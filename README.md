# Curso de CSS — Plan de aprendizaje
 
Este repositorio documenta mi proceso de aprendizaje de **CSS puro** a través de un plan estructurado de 7 días, con ejercicios progresivos y un proyecto integrador final. Todo el CSS fue escrito sin frameworks, partiendo desde los fundamentos hasta efectos y animaciones.
 
---
 
## 📅 Día 1 — Fundamentos de CSS
 
Selectores (etiqueta, clase, ID, descendiente, universal), propiedades de texto y color, herencia y vinculación de hoja de estilos externa.
 
**Resultado:** Primera hoja de estilos aplicada sobre una página de presentación personal y una página de película favorita con paleta de colores y tipografía definidas.
 
---
 
## 📅 Día 2 — El Box Model
 
Modelo de caja (contenido, `padding`, `border`, `margin`), `box-sizing: border-box`, `max-width` con `margin: 0 auto`, `border-radius` y propiedad `display`.
 
**Resultado:** Página de torneo de videojuegos y restaurante con contenedores centrados, espaciados controlados y tabla con bordes y padding correcto.
 
---
 
## 📅 Día 3 — Flexbox
 
Layout unidimensional con `display: flex`, `flex-direction`, `justify-content`, `align-items`, `flex-wrap`, `gap`, `flex` y `flex-shrink`.
 
**Resultado:** Blog de tecnología con header, contenido principal y aside en fila. Tienda tecnológica con tarjetas de productos y formulario de contacto estilizados.
 
---
 
## 📅 Día 4 — CSS Grid
 
Layout bidimensional con `grid-template-areas`, `grid-area`, unidad `fr`, `repeat()`, `gap`, `grid-column: span`, `auto-fit` y `minmax()`.
 
**Resultado:** Academia de programación y festival de cine con layouts completos usando `grid-template-areas` en el `body` y en el `main`, aside persistente y secciones internas en Grid.
 
---
 
## 📅 Día 5 — Responsive Design
 
`<meta name="viewport">`, media queries con `@media`, breakpoints, filosofía Desktop First y unidades relativas (`%`, `vw`, `vh`, `rem`).
 
**Resultado:** Blog y tienda adaptados para tablet y móvil, con columnas que se apilan, aside a ancho completo y tipografía ajustada según el dispositivo.
 
---
 
## 📅 Día 6 — Efectos y transiciones
 
Pseudo-clases (`:hover`, `:focus`, `:nth-child`), `transition`, `transform` (`translate`, `scale`, `rotate`), `box-shadow`, pseudo-elementos `::before` y `::after`, y animaciones con `@keyframes`.
 
**Resultado:** Tarjetas con efecto hover, campos con resplandor al focus, animaciones de entrada en títulos, efecto ripple en botones y subrayado animado con `::after`.
 
---
 
## 📅 Día 7 — Proyecto integrador: PulseGym
 
Sitio web completo de un gimnasio moderno construido desde cero con HTML y CSS, aplicando todos los conceptos del curso de forma independiente.
 
---
 
## 🛠️ Tecnologías usadas
 
- HTML5 semántico
- CSS3 puro (sin frameworks)
